# Fase 2 - Microsoft - Front-End

Estructura intermedia con referencia MVC.

- 7 páginas HTML independientes.
- CSS general + CSS separado para cada página.
- JS general + JS separado para cada página.
- app/models, app/controllers y app/views como organización MVC.
- Variables y nombres de programación en camelCase.
- Código comentado y pensado para ser explicado por un estudiante.
- HTML5 semántico y Bootstrap 5.3.3.

Contenido basado en la Fase 1: historia, misión, visión, valores, objetivos, soluciones, certificaciones, FAQ, blog y contacto.
